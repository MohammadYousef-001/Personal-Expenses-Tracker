# Data Plan

This document defines the data source, fixture path, authentication requirements, possible failure modes, and example response for each P0 tool in the Personal Expense Tracker MCP.

| Tool | Source | Fixture Path | Auth | Failure Modes | Example Response |
|---|---|---|---|---|---|
| `add_expense` | Local CSV file | `./data/expenses.csv` | None | File not found, missing CSV headers, malformed CSV row, invalid amount, invalid category, invalid date, write failure | `{"success":true,"expense":{"id":"expense-004","amount":15,"category":"Food","date":"2026-08-03","description":"Coffee"}}` |
| `list_expenses` | Local CSV file | `./data/expenses.csv` | None | File not found, empty CSV file, missing CSV headers, malformed CSV row, invalid month filter, invalid category filter | `{"expenses":[{"id":"expense-001","amount":45,"category":"Food","date":"2026-08-01","description":"Groceries"},{"id":"expense-002","amount":20,"category":"Transport","date":"2026-08-01","description":"Taxi"}],"count":2}` |
| `get_spending_summary` | Local CSV file | `./data/expenses.csv` | None | File not found, empty CSV file, missing CSV headers, malformed CSV row, invalid amount in a row, invalid month filter, no matching expenses | `{"month":"2026-08","totalAmount":165,"expenseCount":3,"categoryTotals":{"Food":45,"Transport":20,"Bills":100}}` |

## Notes
- Expense IDs are generated by the server when a new expense is added.
- All three P0 tools use `./data/expenses.csv`.
- No API key or internet connection is required.
- The CSV fixture allows the project to work offline during Demo Day.
- The server generates the ID before saving a new expense to the CSV file.

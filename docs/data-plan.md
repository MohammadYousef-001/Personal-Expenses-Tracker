# Data Plan

This document defines the data source, fixture file, authentication requirements, possible failure modes, and example response for each P0 tool in the Personal Expense Tracker MCP.


| Tool | Source | Fixture Path | Auth | Failure Modes | Example Response |
|---|---|---|---|---|---|
| `add_expense` | Local JSON file | `data/expenses.json` | None | Invalid amount, invalid category, invalid date format, file not found, invalid JSON, write failure | `{"success":true,"expense":{"id":"expense-004","amount":15,"category":"Food","date":"2026-08-01","description":"Coffee"}}` |
| `list_expenses` | Local JSON file | `data/expenses.json` | None | Invalid month format, invalid category, file not found, invalid JSON, no matching expenses | `{"expenses":[{"id":"expense-001","amount":45,"category":"Food","date":"2026-08-01","description":"Groceries"},{"id":"expense-002","amount":20,"category":"Transport","date":"2026-08-01","description":"Taxi"}],"count":2}` |
| `get_spending_summary` | Local JSON file | `data/expenses.json` | None | Invalid month format, file not found, invalid JSON, no expenses found for the selected month | `{"month":"2026-08","totalAmount":165,"expenseCount":3,"categoryTotals":{"Food":45,"Transport":20,"Bills":100}}` |



## Notes
- Expense IDs are generated by the server when a new expense is added.
- Clients provide only the fields defined in the input schema.
- All tools use the same local JSON fixture.
- No authentication is required.
- No paid API or internet connection is required.
- The local fixture allows the MCP server to work during Demo Day without Wi-Fi.
